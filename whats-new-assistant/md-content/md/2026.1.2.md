## Studio Labs features available

Studio Labs lets you try out the latest AI experimental features in a stable
version of Android Studio, so you can more quickly integrate our AI assistance
offerings in your development workflow. To enable the features, go to
**Studio Labs** in settings.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)

## More agent skills

Android Studio supports agent skills, which are modular instruction sets that
ground the agent in specialized workflows and domain-specific knowledge. We've
added more Android skills to our repo, which lets you teach the agent to follow
specific best practices, architecture patterns, and workflows, enabling more
accurate, context-aware code generation.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/more-agent-skills)

## Parallel conversations

![Use the History icon to navigate between active tasks.](https://developer.android.com/studio/releases/assistant/2026.1.2/parallel-chats.png)

You can run multiple conversations in Agent Mode in parallel, enabling you to
multitask more effectively. For example, you can kick off a long-running test
generation task in one chat thread while using a second conversation thread to
plan a new feature.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/parallel-conversations)

## LeakCanary in Android Studio Profiler

![Review memory leaks identified via LeakCanary through the Fix with Agent button.](https://developer.android.com/studio/releases/assistant/2026.1.2/leakcanary.png)

Android Studio Quail 2 includes a
[LeakCanary](http://square.github.io/leakcanary/) integration directly in the
Android Studio Profiler as a dedicated task.

The LeakCanary profiler task in Android Studio actively moves the memory
analysis from your device to your development machine, resulting in a
significant performance boost during the leak analysis phase as compared with
on-device leak analysis.

Additionally, the leak analysis is now contextualized within the IDE and fully
integrated with your source code, providing features like **Jump to Source**
and other helpful code connections that drastically reduce the friction and
time required to investigate and fix memory leaks. You can also copy the entire
leak analysis for further processing with Gemini. This can dramatically
increase your productivity and improve your workflow during the development
phrase.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/leakcanary)
