# What's New in Rabbit 1

**[Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2026-2-1)**

![Rabbit 1 icon](https://developer.android.com/static/studio/images/splash-screens/rabbit-1.png)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Compose Preview Screenshot Testing tool

![Test Compose UIs with the screenshot testing tool](https://developer.android.com/studio/releases/assistant/images/compose-screenshot-testing.png)

Use the Compose Preview Screenshot Testing tool to test your Compose UIs and
mitigate regressions. The new tool helps you generate HTML reports that let you
visually detect any changes to your app's UI.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/compose-screenshot)

## Publish to Google Play for testing

![Publish an app to Play for testing](https://developer.android.com/studio/releases/assistant/images/publish-to-play.png)

Android Studio now gives you the ability to upload new releases of your app
directly to Google Play Console test tracks. You can do this by selecting a new
option to continue to 'Publish for Testing' at the end of the Generate Signed
App Bundle flow. This integration supports uploading an initial release of a
brand-new app to a Play Console internal test track. You can also use this
feature to upload releases of existing apps to other types of test tracks. You
need to be registered on Google Play Console to take advantage of this
functionality.

[Learn more ↗](https://d.android.com/r/studio-ui/publish/google-play-testing)

## Android Studio is part of the Gemini Enterprise bundle

![Signing in to Android Studio with a Gemini Enterprise subscription](https://developer.android.com/studio/images/ge-onboarding.png)

Android Studio is now included in the [Gemini Enterprise subscription
bundle](https://cloud.google.com/gemini-enterprise), enabling enterprise
development teams to deploy Android Studio using models hosted directly in your
organization's Google Cloud infrastructure under enterprise security controls,
data residency guarantees, and the Google Cloud Terms of Service.

[Learn more ↗](https://d.android.com/r/studio-ui/ai/gemini-enterprise)

## Model Assignment

![Model Assignment
setting](https://developer.android.com/studio/releases/assistant/images/model-assignment-wna.png)

The Model Assignment feature lets you pick different AI models for different
types of tasks in Android Studio. To configure this, go to **File** (**Android
Studio** on macOS) **> Settings > Tools > AI > Model Providers**, select the
**Model Assignment** tab, and use the dropdowns to assign a model for each
feature category.

[Learn more ↗](https://d.android.com/r/studio-ui/ai/model-assignment)

## Studio Labs features available

![Studio Labs in settings](https://developer.android.com/studio/releases/assistant/images/studio-labs.webp)

Studio Labs lets you try out the latest AI experimental features in a stable
version of Android Studio, so you can more quickly integrate our AI assistance
offerings in your development workflow. Studio Labs features are enabled by
default in canary versions of Android Studio.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)
