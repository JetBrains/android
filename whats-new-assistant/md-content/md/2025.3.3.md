# What's New in Panda 3

### [Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2025-3-3)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Studio Labs features available

Studio Labs lets you try out the latest AI experimental features in a stable version
of Android Studio, so you can more quickly integrate our AI assistance offerings in your
development workflow. To enable the features, go to **Studio Labs** in settings.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)

## Manage permissions in Agent Mode

You now have more fine-grained control over permissions in Agent Mode. When you're
working with the agent, it will prompt you when it needs to perform actions that you
haven't previously granted permission for. Android Studio uses an intelligent request
system so that you can have the agent work without interruption on operations you trust,
and still do manual review for other operations. You can always manually audit your
permissions at **File** (**Android Studio** on macOS) > **Settings > Tools >
AI > Agent Permissions**.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/permissions)

## Skills for Agent Mode

Starting in Android Studio Panda 3, you can use skills to enhance Agent
Mode's capabilities with specialized expertise and custom workflows.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/skills)
