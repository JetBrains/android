## Suggested fixes for crashes

![App Quality Insights integrated with AQI](https://developer.android.com/static/studio/images/agent-integration-aqi.png)

In Android Studio Meerkat Feature Drop, we launched Gemini insights for crashes
reported in the
[App Quality Insights](https://d.android.com/studio/debug/app-quality-insights)
tool window. Now, Android Studio can use Gemini to analyze the crash data along
with your source code to suggest potential fixes. After selecting a crash in the
App Quality Insights tool window, navigate to the **Insights** tab and click
**Suggest a fix** after Gemini generates an insight for the crash. Gemini then
generates suggested code changes that you can review and accept in an editor
diff tab.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/suggested-fixes)
