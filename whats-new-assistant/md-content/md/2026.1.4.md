# What's New in Quail 4

**[Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2026-1-4)**

![Quail 4 icon](https://developer.android.com/static/studio/images/splash-screens/quail-4.png)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Build full-stack apps with Firebase in Agent Mode

![The agent guiding a user through Firebase integration in the chat interface](https://developer.android.com/studio/releases/assistant/2026.1.4/build-full-stack-apps-with-firebase-agent-mode.png)

Firebase services like Authentication and Cloud Firestore databases can be
enabled and configured directly in Agent Mode in Android Studio using Firebase
agent skills. The agent can help you complete Firebase integration and
configure backend services without leaving the IDE.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/firebase-agent-mode)

## Build Android apps in Google AI Studio

Google AI Studio supports full Android app development capabilities. You can
generate new apps from natural language, preview them instantly in an embedded
emulator, and deploy directly to physical devices or upload test packages
straight to the Google Play Console testing tracks.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/google-ai-studio)

## Android CLI

Android CLI enables you to build apps using any AI agent, LLM, or development
environment of your choice. It is designed to help AI agents build faster and
use fewer tokens. It also enables agents to call into Android Studio to find
symbol declarations and analyze files for issues.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/android-cli)

## Compose Preview Screenshot Testing tool

Use the Compose Preview Screenshot Testing tool to test your Compose UIs and
mitigate regressions. The new tool helps you generate HTML reports that let you
visually detect any changes to your app's UI.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/compose-screenshot)

## Recomposition state reads in the Layout Inspector

![Recomposition state reads in the Layout Inspector](https://developer.android.com/studio/releases/assistant/2026.1.4/recomposition-inspect.png)

We've made it easier to diagnose high
[recomposition](https://developer.android.com/develop/ui/compose/mental-model#recomposition)
counts by adding recomposition state reads to the
[Layout Inspector](https://developer.android.com/studio/debug/layout-inspector).
Available in Quail 4 canary, this feature helps you identify the state
variables that triggered a recomposition by providing a detailed list of state
reads performed during that cycle.

[Learn more ↗](https://d.android.com/r/studio-ui/design/layout-inspector-state-reads)

## Publish to Google Play for testing

![Publish an app to Play for testing](https://developer.android.com/studio/releases/assistant/2026.1.4/publish-to-play.png)

Android Studio now gives you the ability to upload new releases of your app
directly to Google Play Console test tracks. You can do this by selecting a new
option to continue to 'Publish for Testing' at the end of the Generate Signed
App Bundle flow. This integration supports uploading an initial release of a
brand-new app to a Play Console internal test track. You can also use this
feature to upload releases of existing apps to other types of test tracks. You
need to be registered on Google Play Console to take advantage of this
functionality.

[Learn more ↗](https://d.android.com/r/studio-ui/publish/google-play-testing)

## Gemma 4 integration

![Selecting Gemma 4 from models](https://developer.android.com/studio/releases/assistant/2026.1.4/gemma-4.png)

You can now run the powerful Gemma 4 model directly within Android Studio for AI
code assistance without relying on a third-party provider to host it. Powered
natively by an integrated runtime, this local execution gives you full control
to design new features, refactor code, and debug issues—all completely
on-device. To download Gemma models, go to **Settings > Tools > AI > Model
Providers > Gemma**.

[Learn more ↗](https://d.android.com/r/studio-ui/ai/gemma-4)

## Simulate back navigation transitions with Interactive Preview

![Simulate transitions in Interactive Preview](https://developer.android.com/studio/releases/assistant/2026.1.4/interactive-preview.png)

Quail 4 introduces dedicated controls—including a **Navigate Back** action and a
**Predictive Back Progress** slider—allowing you to test back and forward
animations without deploying to a physical device or emulator. You can now step
through custom transition states and verify predictive back gesture behavior
directly within [Compose Interactive
Preview](https://dev.android.com/develop/ui/compose/tooling/previews#preview-interactive).

[Learn more ↗](https://d.android.com/r/studio-ui/design/simulate-back-nav)

## Studio Labs features available

Studio Labs lets you try out the latest AI experimental features in a stable
version of Android Studio, so you can more quickly integrate our AI assistance
offerings in your development workflow. Studio Labs features are enabled by
default in canary versions of Android Studio.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)
