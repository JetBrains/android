# What's New in Quail 3

### [Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2026-1-3)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Studio Labs features available

Studio Labs lets you try out the latest AI experimental features in a stable version
of Android Studio, so you can more quickly integrate our AI assistance offerings in your
development workflow. Studio Labs features are enabled by default in canary versions of
Android Studio.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)

## Build full-stack apps with Firebase in Agent Mode

Firebase services like Authentication and Cloud Firestore databases
can be enabled and configured directly in Agent Mode in Android Studio
using Firebase agent skills. The agent can help you complete Firebase
integration and configure backend services without leaving the IDE.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/firebase-agent-mode)

## More capabilities when creating a new project with AI

Creating new projects with AI has evolved into a full-stack
development tool: it uses a multi-step execution plan and an autonomous
generation loop to configure dependencies across multiple files and
self-correct build errors. This is further enhanced by integration with
Firebase agent skills and support for large screen device optimizations.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/create-new-project-with-ai)

## Build Android apps in Google AI Studio

Google AI Studio supports full Android app development capabilities.
You can generate new apps from natural language, preview them instantly in
an embedded emulator, and deploy directly to physical devices or upload
test packages straight to the Google Play Console testing tracks.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/google-ai-studio)

## Android CLI

Android CLI enables you to build apps using any AI agent, LLM, or
development environment of your choice. It is designed to help AI
agents build faster and use fewer tokens. It also enables agents to
call into Android Studio to find symbol declarations and analyze
files for issues.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/android-cli)

## Compose Preview Screenshot Testing tool

Use the Compose Preview Screenshot Testing tool to test your Compose UIs and mitigate
regressions. The new tool helps you generate HTML reports that let you visually detect any
changes to your app's UI.

[Learn more ↗](https://d.android.com/r/studio-ui/debug/compose-screenshot)

## Recomposition state reads in the Layout Inspector

We've made it easier to diagnose high
[recomposition](https://developer.android.com/develop/ui/compose/mental-model#recomposition)
counts by adding recomposition state reads to the
[Layout Inspector](https://developer.android.com/studio/debug/layout-inspector).
Available in Quail 2 canary, this feature helps you identify the state variables that
triggered a recomposition by providing a detailed list of state reads performed during
that cycle.

[Learn more ↗](https://d.android.com/r/studio-ui/design/layout-inspector-state-reads)
