# What's New in Quail 3

**[Read in a browser ↗](https://d.android.com/r/studio-ui/whats-new-assistant/preview-release-notes/2026-1-3)**

![Quail 3 icon](https://developer.android.com/static/studio/images/splash-screens/quail-3.png)

This panel describes some of the new features and behavior changes
included in this update.

To open this panel again later, select **Help > What's New in Android Studio**
from the main menu.

## Improvements to Planning Mode

Planning Mode facilitates a multi-stage reasoning process, giving the agent
more space to evaluate its own proposed logic for potential issues before
presenting it to you. You can explicitly kick off Planning Mode by including
the **/plan** command in your prompt, or by asking the agent to generate a
plan before it starts implementing code.

[Learn more ↗](https://d.android.com/r/studio-ui/tools/planning-mode)

## MCP Marketplace

![The MCP Marketplace tab in Studio settings](https://developer.android.com/studio/releases/assistant/2026.1.3/mcp-marketplace.png)

Starting in Quail 3, we're making it easier for you to find and add MCP servers.
Navigate to **Settings > Tools > AI > MCP Servers** to browse for a server and
install it.

The **Marketplace** tab lists all the servers available on
[ModelContextProtocol.io](http://modelcontextprotocol.io/). Click the gear
icon to switch to a custom registry or to filter by MCP server type (such as
**NPX**, **Docker**, or **Python**).

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/mcp-marketplace)

## Merge Conflicts action

Quail 3 introduces a new **Merge Conflicts with Agent** button into the
**Commit** tool window that instructs the agent to automatically merge
conflicts. When there are one or more conflicting files in the repositories,
you can click this button to launch a new agent session targeting those files.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/merge-conflicts-action)

## Studio Labs features available

Studio Labs lets you try out the latest AI experimental features in a stable
version of Android Studio, so you can more quickly integrate our AI assistance
offerings in your development workflow. To enable the features, go to **Studio
Labs** in settings.

[Learn more ↗](https://d.android.com/r/studio-ui/gemini/labs)
